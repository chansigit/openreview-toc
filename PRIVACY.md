# Privacy Policy — OpenReview Reviewer TOC

Effective date: November 17, 2026

OpenReview Reviewer TOC is maintained by [chansigit](https://github.com/chansigit). It adds a local navigation sidebar to OpenReview paper discussions.

## Information processed on your device

On `https://openreview.net/`, the extension checks the current page URL to decide whether to show the sidebar and identify the paper. On paper discussion pages, it reads metadata already present in the page: review types, note identifiers, displayed reviewer or author names and aliases, reply titles, and the relationships between reviews and replies. These fields can include personal information and metadata from discussions visible to your OpenReview account, including private discussions.

This information is used only to build the table of contents, keep it updated, and expand or scroll to the item you select. The extension also handles clicks, keyboard input, and drag coordinates solely to operate its interface; it does not record interaction logs or analytics. It does not reveal anonymous identities or bypass OpenReview access controls.

## Storage and sharing

The extension processes this information in the current browser page and temporary memory. It does not persist discussion data, browsing history, or sidebar positions in browser storage or on a server. Closing or reloading the page clears its temporary state.

The extension makes no network or API requests and does not transmit page data to the developer or any third party. It does not sell data, use it for advertising, use it for purposes unrelated to discussion navigation, or use it for creditworthiness or lending decisions. It includes no analytics, tracking SDKs, or remotely executed code.

It does not read passwords, authentication cookies, payment information, or your browser's history database. OpenReview itself continues to handle its own website and account data under its own policies. If you visit this project's GitHub pages or voluntarily file an issue, GitHub processes that activity under its own privacy policy; the extension does not send it automatically.

## Your choices and contact

You can disable or remove the extension in `chrome://extensions`. There is no developer-held database of extension usage or discussion content to delete. Please do not include confidential review content in public support issues.

For privacy questions, contact the maintainer through [GitHub Issues](https://github.com/chansigit/openreview-toc/issues). Changes to this policy will be posted here with an updated effective date.

# 隐私政策 — OpenReview Reviewer TOC

生效日期：2026 年 11 月 17 日

本扩展由 [chansigit](https://github.com/chansigit) 维护，用于在 OpenReview 论文讨论页显示本地导航目录。

## 在设备上处理的信息

扩展会检查 `https://openreview.net/` 当前页面的网址，以判断是否显示目录并识别论文。在论文讨论页，它读取页面中已有的评审类型、条目标识符、公开显示给当前用户的审稿人或作者姓名及匿名署名、回复标题，以及评审和回复的层级关系。这些字段可能包含个人信息，也可能来自你的 OpenReview 账号有权查看的非公开讨论。

这些信息仅用于生成和更新目录，以及展开、跳转到你选择的条目。点击、按键和拖动坐标仅用于操作界面，不会被记录为行为日志或分析数据。扩展不会揭示匿名身份，也不会绕过 OpenReview 的访问权限。

## 存储与分享

信息仅在当前浏览器页面及临时内存中处理。扩展不会将讨论数据、浏览历史或目录位置持久保存到浏览器存储或服务器；关闭或刷新页面会清除临时状态。

扩展不发起网络或 API 请求，不向开发者或第三方传输页面数据，不出售数据，不将数据用于广告、与讨论导航无关的用途、信用评估或贷款决策。扩展没有统计分析、跟踪 SDK 或远程执行的代码。

扩展不读取密码、身份验证 Cookie、支付信息或浏览器历史数据库。OpenReview 自身的网站和账号数据处理遵循其自身政策。你主动访问项目的 GitHub 页面或提交问题时，该活动由 GitHub 按其政策处理，并非扩展自动发送。

## 你的选择与联系方式

你可以在 `chrome://extensions` 停用或移除扩展。开发者没有需要删除的扩展使用记录或讨论内容数据库。请勿在公开支持问题中附上保密评审内容。

隐私相关问题可通过 [GitHub Issues](https://github.com/chansigit/openreview-toc/issues) 联系维护者。政策变更将在本页公布，并更新生效日期。
